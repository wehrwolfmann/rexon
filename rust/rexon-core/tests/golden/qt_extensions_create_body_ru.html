Расширение Rexon — это обычный ZIP-архив с расширением .rxn. Структура одинакова для всех типов:

расширение.rxn (ZIP):
├── manifest.json     ← ОБЯЗАТЕЛЬНО (format_version: 3)
├── preview.png       ← 620×348 (для каталога/карточек)
├── icon.png          ← 128×128 (списки в Rexon)
├── install.sh        ← для desktop-tool / plugin
├── uninstall.sh      ← для desktop-tool / plugin
├── app.desktop       ← для desktop-tool
├── README.md         ← опционально, описание
└── data/             ← файлы расширения

📋 Минимальный manifest.json

{
  "format_version": 3,
  "id": "my-cool-theme",
  "name": "Моя крутая тема",
  "version": "1.0.0",
  "author": "Я",
  "description": "Что делает расширение",
  "type": "theme-gtk",
  "tags": ["dark", "modern"],
  "license": "MIT",
  "homepage": "https://github.com/me/my-theme",
  "de_support": ["any"]
}

🎨 Категории (поле type)

Оформление — Rexon ставит файлы автоматически:
theme-gtk, theme-icons, theme-cursors, theme-sounds, theme-kde-global, theme-kde-colors, theme-kde-plasma, theme-kvantum, theme-window-decoration, theme-login-screen, theme-plymouth, theme-conky, theme-bundle, theme-plasmoid, wallpaper-pack, font-pack

Кастомизация окружений — Rexon кладёт в каталог этого рабочего стола и включает его же средствами:
kde-kwin-script, kde-kwin-effect, kde-window-switcher, kde-wallpaper-plugin, theme-kde-splash, theme-kde-lockscreen, gnome-shell-extension, theme-gnome-shell, cinnamon-applet, cinnamon-desklet, cinnamon-extension, theme-cinnamon, nemo-action, theme-xfwm4, theme-marco, theme-lxqt

Расширения (предупреждение при установке — выполняется код):
desktop-tool, plugin

📦 Сборка

cd my-extension/
zip -r ../my-extension.rxn .

Готовый .rxn можно перетащить в окно Rexon или нажать 「📦 Из файла」.

В исходниках Rexon: extensions/constants.py — полный список типов и путей установки.
