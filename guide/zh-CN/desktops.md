# 桌面环境

在这个标签页里可以安装、切换和卸载桌面环境。还可以在这里检查你的桌面是否完整，
把各个桌面放在一起对比，并一键让桌面看起来像某个知名发行版。

![“桌面环境”标签页：左侧是列表，中间是“发行版风格”和“工具”，右侧是桌面卡片](../images/desktops-overview.png)

## 标签页上有什么

**桌面列表（左侧）。** 桌面分为几组：“经典”（Cinnamon、XFCE、MATE、GNOME、
KDE Plasma、Budgie、Pantheon、Deepin、COSMIC、LXQt）、“平铺”（Hyprland、niri、
Sway、River）和“带特效的合成器”（Wayfire）。如果某个桌面无法在你的发行版上安装，
列表中会直接注明。

**桌面卡片（右侧）**：所选桌面的全部信息：

- 屏幕截图（箭头用于翻页，点击放大镜或图片可全屏查看）；
- 状态：“已安装”、“未安装”、“当前桌面”；
- 简短介绍和四项评分：“内存”（刚登录后占用多少）、“处理器”、“可定制性”和“游戏”；
- 该桌面的软件包已经装了多少、缺少哪些、哪些有更新；
- 已安装的版本，以及软件仓库中更新的版本（如果有）；
- 操作按钮：
  - **📦 安装**：用于尚未安装的桌面；
  - **🔄 切换**：注销当前会话并登录到这个桌面；
  - **🔧 检查 / 修复**：找出并补装缺少的软件包；
  - **🗑️ 移除**：移除这个桌面。当前桌面没有这个按钮；
  - **➕ 添加 Wayland 版本**：用于已安装、既能在 X11 又能在 Wayland 上运行、
    但尚未安装 Wayland 版本的桌面。
- Hyprland、niri 和 Sway 有 **“外壳”** 区块：自带启动菜单和通知的现成面板
  （Noctalia、DankMaterialShell）。可以安装它们、带着它们登录，或卸载它们。

**🎨 发行版风格（中间）。** 一次性套用某个知名发行版的完整外观：目前有
“SteamOS 风格”和“Garuda Linux 风格（Dr460nized）”。已应用的风格会出现
**↩️ 还原** 按钮。

**🧰 工具（在其下方）：**

- **⚔️ 对比桌面**：所有桌面并列的表格；
- **🔧 检查我的桌面**：与“检查 / 修复”相同，但针对你当前正在使用的桌面；
- **🛟 保存面板** 和 **↩️ 恢复面板**：保存面板设置的副本，以防折腾主题时把面板弄坏。
  所有副本都在 **设置 → 🛡️ 面板保护** 中。

![已安装桌面的卡片，带有“切换”、“检查 / 修复”和“移除”按钮](../images/desktops-installed.png)

## 操作步骤

### 安装桌面

1. 在左侧列表中选择一个桌面。
2. 点击 **📦 安装**。
3. 在“安装？”窗口中确认要安装的内容。如果该桌面提供“桌面的运行方式”选项，
   请选择一种（见下文）。
4. 确认，并在系统询问时输入管理员密码。
5. 出现“安装完成”后，注销当前会话，在登录界面选择新桌面。如果该桌面需要重启，
   Rexon 会在同一个窗口里说明。

### 选择 X11 还是 Wayland

Cinnamon、XFCE、MATE 和 LXQt 有两种运行方式。选项直接出现在“安装？”窗口的
“桌面的运行方式”一行中：

- **X11——成熟稳定**：桌面多年来一直这样运行，所有程序和设置都能正常工作；
- **Wayland——更新**：在高分辨率屏幕上画面更流畅、更清晰。部分桌面的 Wayland
  版本仍是实验性的：一些程序、面板小程序和设置可能无法使用；
- **Wayland——实验性，来自 AUR**：MATE 的 Wayland 版本带有此标记：它会在你的电脑上
  从 AUR 构建，Rexon 会在窗口中直接提醒这一点。

推荐的选项标有“（推荐）”。如果选择 Wayland，X11 版本也会保留，登录界面上两者都有。
Rexon 最后会提示登录时应选择哪个会话。Wayland 版本也可以以后再添加：使用卡片上的
**➕ 添加 Wayland 版本** 按钮。

### 切换到另一个桌面

1. 在列表中选择一个已安装的桌面。
2. 点击 **🔄 切换**。
3. 保存打开的文档并确认。Rexon 会保存当前桌面设置的副本并结束会话。
4. 在登录界面选择新桌面。

### 卸载桌面

1. 选择桌面并点击 **🗑️ 移除**。
2. 在“卸载？”窗口中，Rexon 会显示当前正在使用的是哪个桌面——它不会受影响。
   确认并输入密码。

以下桌面无法卸载：

- **当前桌面**：否则下次登录后会是黑屏。请先切换到另一个桌面，登录进去，然后再卸载；
- **最后一个已安装的桌面**：请先安装另一个桌面。

与其他程序共用的软件包会保留：只删除不再被任何软件需要的部分。

### 检查和修复桌面

如果桌面表现异常（面板消失、设置打不开），请点击“工具”中的 **🔧 检查我的桌面**，
或任意已安装桌面卡片上的 **🔧 检查 / 修复**。Rexon 会核对该桌面的软件包清单，
并补装缺少的软件包。如果卡片上已经显示缺少软件包，这个按钮正好会把它们装上。

### 对比桌面

点击 **⚔️ 对比桌面**。会打开“所有桌面环境”表格：内存、处理器负载、桌面基于什么构建、
由什么绘制窗口。每一行都可以展开。“快速对比”按钮会把常见的对比并排显示
（例如 XFCE ↔ KDE）。点击 **← 桌面环境** 返回。

![桌面对比](../images/desktops-compare.png)

### 让桌面变成“发行版风格”

1. 在 **🎨 发行版风格** 区块中，点击所需风格上的 **应用**。
2. Rexon 会检查需要什么，并显示一个窗口：哪些会改变，哪些在你的桌面上只能部分应用，
   哪些完全无法应用。SteamOS 风格可以选择样式，并可按需开启游戏模式。
3. 点击 **应用**。如果该风格需要额外的程序，Rexon 会安装它们并询问密码。
4. 改主意了？点击 **↩️ 还原**：原来的外观和设置都会恢复。为该风格安装的程序会保留，
   你可以自行卸载。

![“应用“SteamOS 风格”？”窗口，显示改动列表](../images/desktops-looks.png)

## 出了问题怎么办

- **安装后登录界面上没有这个桌面。** 再注销一次。如果 Rexon 提示需要重启，请重启电脑。
  对于 Cinnamon、XFCE、MATE 和 LXQt，请检查你选择的是哪种会话（X11 还是 Wayland）。
- **桌面启动后没有面板或出现错误。** 登录到任意其他桌面，或者留在这个桌面里，
  点击 **🔧 检查我的桌面**。
- **主题把面板弄坏了。** 如果你事先点过 **🛟 保存面板**，现在点击 **↩️ 恢复面板**。
- **不喜欢某个“发行版风格”。** 点击它卡片上的 **↩️ 还原** 按钮。
- **“软件包已不再更新”窗口。** 系统里留有一个已经从软件仓库中移除的软件包。
  如果你不用它，Rexon 可以把它卸载；否则请点击“暂不”。
- **“未检测到桌面”。** Rexon 没能识别你正在使用的桌面。请在左侧列表中选中它，
  然后点击其卡片上的 **🔧 检查 / 修复**。
- **需要回滚整个系统。** Rexon 本身不创建系统快照。如果你配置了 snapper 和 snap-pac
  （CachyOS 和其他使用 Btrfs 的发行版常这样配置），每次安装和卸载软件包之前都会自动
  创建快照，可以用 snapper 的工具（例如 Btrfs Assistant）回到快照。
- **切换后 KDE Plasma 的面板不见了。** 从 Plasma 切换出去之前，Rexon 会保存它的面板；
  可以在 **设置 → 🛡️ 面板保护** 中恢复。如果新桌面抢走了默认浏览器或
  播放器，请查看 **设置 → 🔒 默认应用保护**。
