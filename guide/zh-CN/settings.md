# 设置

这里用来设置 Rexon 本身（语言、窗口外观、托盘图标），以及整台电脑共用的几项设置：
用哪个文件管理器打开文件夹、默认用哪些程序打开文件、图片或视频壁纸、环境音和事件声音。
各个版块从上到下排成一列；有些版块只在有意义的地方出现（例如面板保护只在 Rexon
能够保存其面板的桌面上出现）。

![“设置”标签页：语言、界面皮肤、导览](../images/settings-top.png)

## 标签页上有什么

| 版块 | 用途 |
| --- | --- |
| 🌐 **语言** | Rexon 窗口、菜单和消息的语言 |
| 🎨 **界面皮肤** | Rexon 自身窗口的配色 |
| **首次启动时显示导览** | 显示在窗口上方的简短提示 |
| 🔔 **系统托盘图标** | 时钟旁的图标和开机自启 |
| 📁 **文件管理器** | 用哪个程序打开文件夹 |
| 🔧 **快速恢复应用** | 恢复当前桌面自带的程序 |
| 🧩 **桌面完整性** | 检查桌面所需的组件是否都已安装 |
| 🎬 **壁纸（图片 / 视频 / YouTube / 网页）** | 来自文件的壁纸、YouTube 或 Vimeo 视频、网页 |
| 📚 **壁纸库** | Rexon 壁纸包（.rxn） |
| 🪟 **导入 Windows 主题** | 把旧 Windows 电脑上的外观搬过来 |
| 🔒 **默认应用保护** | 不让新桌面替换你的程序 |
| 🛡️ **面板保护** | 任何桌面的面板、小程序和键盘快捷键的副本 |
| 🪟 **桌面外观** | 仅在安装了 Plasma 外观分支版本（AeroShell 等）时出现 |

动画、字体、窗口标题栏按钮、程序启动反馈、程序中的图标、壁纸模糊、环境音和事件声音位于“外观”标签页——KDE 系统
设置也把它们放在那里。

如果你已经输入过密码，标签页顶部会显示一条“🔓 在关闭窗口前，Rexon 可以更改系统”。
**“立即撤销”** 按钮会收回这项授权：下次 Rexon 会再次询问密码。

## 如何更改语言和皮肤

1. 在 **🌐 语言** 版块的列表中选择语言。第一项是“跟随系统”。
2. 语言在 Rexon 重新启动后才会更改：点击 **“重新启动 Rexon”**。
3. 在 **🎨 界面皮肤** 版块中选择窗口外观：“深色（Steam）”（默认）、“浅色”、
   “深色（Material）”、“Synthwave / Neon Space Retro”或“系统（跟随系统主题）”。
   皮肤会立即更改。

皮肤只是 Rexon 窗口的配色，而不是整个桌面的主题。桌面主题在“外观”标签页中更改。

## 首次启动时的导览

第一次启动时，Rexon 会询问“显示简短导览？”。导览大约需要一分钟，会告诉你在哪里更改
主题、壁纸和外观。

![“显示简短导览？”提问](../images/settings-tour.png)

- **“首次启动时显示导览”** 复选框用于开启或关闭这个提问。
- **“重新查看导览”** 按钮可以随时开始导览。

## 托盘图标和开机自启

![系统托盘图标和文件管理器](../images/settings-tray.png)

Rexon 会在时钟旁放一个图标：无需打开窗口，就能从那里使用壁纸、各个版块和退出功能。
只要图标在，点击窗口的关闭按钮只会把 Rexon 隐藏到托盘，而不是关闭它。

- **“登录时启动”**：登录系统时 Rexon 会启动到托盘中，不显示窗口。
- **“自动下载主题所需的图标和光标”**：如果所选主题缺少图标或光标，Rexon 会把它们下载到
  你的主目录并应用。如果关闭此项，它会先询问你。对于只能以系统软件包安装的组件，
  Rexon 总是会先询问。

如果会话中没有托盘，Rexon 会如实告诉你：图标没有放置，关闭按钮像平常一样关闭程序。

## 文件管理器

选择用哪个程序打开文件夹——在 Rexon 中和整个系统中都一样。
**“自动（跟随桌面）”** 使用当前桌面自带的文件管理器。每一项旁边都显示它是否已安装。
点击 **“应用文件管理器设置”**。Hyprland 和其他窗口管理器没有自己的文件管理器——
列表中的任何一个都可以。

## 如何恢复默认应用

安装另一个桌面后，终端、文件管理器和文本编辑器可能会被换成那个桌面自己的程序。

![快速恢复应用和桌面完整性](../images/settings-quick-restore.png)

**快速方法：** 在 **🔧 快速恢复应用** 版块中点击 **“恢复 … 应用”**（那里写着你的桌面
名称，例如“恢复 MATE 应用”）。

**你自己的程序：** 在 **🔒 默认应用保护** 版块中：

1. 开启 **“开启保护（推荐）”**。
2. 勾选要保护的内容：文件管理器、浏览器、邮件、看图、视频、PDF、压缩包、音乐、终端。
   旁边会显示记住的是哪个程序。
3. 点击 **“📌 立即记住”**：Rexon 会记住你当前的选择。
4. 如果程序仍然被替换了，点击 **“↩️ 还原”**。

![默认应用保护](../images/settings-protection.png)

## 更换主题后的终端配色

有些终端默认从主题中获取文字和背景颜色。遇到不合适的深色主题时，其中的文字可能会变成
黑底深灰字。因此，在更换 GTK 主题、全局主题、配色方案、浅色/深色模式、强调色或
“发行版风格”之后，Rexon 会自动给这类终端一对清晰易读的颜色：深色主题用深色背景浅色文字，
浅色主题用浅色背景深色文字。

- **涉及哪些终端：** mate-terminal、gnome-terminal 和 Tilix（它们默认使用主题颜色），
  以及开启了“使用主题颜色”的 xfce4-terminal 和 Terminator。Konsole、Console、Ptyxis、
  kitty、Alacritty 等使用自己配色方案的终端不受影响。
- **你自己的颜色不受影响。** 如果你在配置文件中自己选了颜色，并且它们清晰可读，
  Rexon 会保留它们。
- **如何关闭：** 在 **🔒 默认应用保护** 版块中取消勾选
  **“防止主题破坏终端配色（推荐）”**。它默认是开启的。
- **如何恢复：** Rexon 会把原来的终端颜色和主题一起记住。“外观”标签页中的
  **“还原到“…”之前”** 按钮（或“发行版风格”上的 **“↩️ 还原”**）也会把它们恢复。

## 面板副本

**🛡️ 面板保护** 会保存您桌面的面板外观、小程序和键盘快捷键，并在安装其他桌面后出现问题时将其恢复。它适用于 Rexon 支持的所有桌面。

1. 点击 **“📦 保存副本”**。按钮上方的提示会说明此桌面上复制了哪些内容。
2. 每个桌面最多保留 10 个副本；最早的一个（**“⭐ 原始副本，Rexon 之前”**）永远不会被删除。
3. 在安装或切换桌面之前，Rexon 会自动为 **所有已安装桌面** 的面板制作副本。
4. 如果面板坏了，在所需副本旁点击 **“恢复”**。其他桌面的副本位于折叠的 **“其他桌面的副本”** 区块中；该桌面会在下次登录时采用此副本。

GNOME、Budgie 和 Pantheon 共用部分快捷键：Rexon 会在询问中列出同样会改变的桌面。

## 壁纸、声音及其他

- **🎬 壁纸**：**“🖼️ 图片…”** 和 **“🎬 视频…”** 用文件设置壁纸（图片 JPG、PNG、WebP；
  视频 MP4、WebM、MKV 等；Flash SWF）。下方可以填写 YouTube 或 Vimeo 链接
  （**画质**、**模式**：“在线播放”或“下载”），以及来自链接或 HTML 文件的网页壁纸。
  YouTube 需要 yt-dlp 程序：如果没有，Rexon 会提议安装它。
  **“⏹️ 停止动态壁纸”** 会移除动态壁纸。
- 同一处还有壁纸声音设置：音量、“其他应用播放声音时静音”和“壁纸被窗口遮挡时暂停”。
  声音设置立即生效，无需重新设置壁纸。

  ![“壁纸”版块](../images/settings-wallpaper.png)

- **🪟 导入 Windows 主题**：**“📥 选择主题文件…”**：主题（.themepack、.theme）、
  视觉样式（.msstyles）、图标、光标和 DreamScene 视频壁纸。转换好的主题会出现在
  “扩展”标签页中。
- **🧩 桌面完整性**：**“检查并补装”** 会检查桌面所需的组件（主题、字体、附加组件）
  是否都已安装，并补装缺少的部分。系统会询问密码。

## 出了问题怎么办

- **语言没有更改。** 点击 **“重新启动 Rexon”**：语言只在重新启动后才会更改。
- **时钟旁没有图标。** 这个会话中没有系统托盘。Rexon 会像普通窗口一样运行；
  “登录时启动”仍会在登录时启动它。
- **无法更改开机自启。** 详细信息见 Rexon 的日志。
- **安装桌面后默认程序被更换了。** 点击 **“恢复 … 应用”**，或默认应用保护中的
  **“↩️ 还原”**。
- **“⚠️ 壁纸引擎未加载——此版块不可用”。** 在壁纸引擎启动之前，壁纸版块无法使用；
  请打开 Wallpaper Engine 标签页，看看它显示了什么。
- **动画或字体不见了。** 它们现在位于“外观”标签页——本标签页底部有直达那里的链接。
