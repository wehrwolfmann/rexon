# 扩展

这个标签页存放 `.rxn` 软件包，这是 Rexon 自己的附加组件格式：主题、壁纸包、字体、
桌面工具和插件。也可以把 Windows 的主题或光标拖到这里，Rexon 会把它们转换为
Linux 可用的格式。

GNOME Shell 和 Cinnamon 扩展不在这里安装，而是在 [外观](appearance.md) 标签页的
“GNOME 扩展”和“Cinnamon 扩展”版块中安装。

![“扩展”标签页，尚未安装任何内容](../images/extensions-overview.png)

## 标签页上有什么

- **视图切换按钮** “网格”（⊞）和“列表”（☰）：带图片的磁贴或紧凑的行。
- **＋ 从文件安装**：选择磁盘上的文件。
- **搜索**：按名称、作者和标签搜索。
- **类型筛选**：“全部”，以及你已安装的每种类型各一个按钮（例如只显示 GTK 主题
  或只显示工具）。
- **计数行**：“已安装”和“已启用”。
- **我的扩展**：已安装的软件包。每个软件包都有：
  - **▶️ 启用** / **⏸️ 禁用**：用于工具、插件和桌面附加组件（KWin 脚本和特效、
    GNOME 扩展、Cinnamon 小程序和桌面小部件、Nemo 动作）。安装后它们处于禁用状态，
    需要你自己启用；
  - **应用**：用于壁纸包；
  - **🗑️ 移除**。

  点击磁贴会打开“扩展”窗口，其中有说明和 **📁 打开文件夹** 按钮。
- **⬇️ 安装**：三种方式：
  - **从文件**：打开 `.rxn`、`.themepack` 或 Windows 主题；
  - **Steam 创意工坊——即将推出**：目前还不可用，以后会提供；
  - **自己制作**：说明如何制作自己的扩展。

## 操作步骤

### 安装扩展

1. 点击 **＋ 从文件安装**（或“⬇️ 安装”版块中的 **从文件**）。
2. 选择一个 `.rxn` 文件。
3. 等待窗口底部出现“✅ 已安装：…”。

还有更简单的办法：把文件直接拖进 Rexon 窗口。

### 安装 Windows 的主题或光标

拖进窗口，或通过 **从文件** 打开：

- 主题：`.themepack`、`.deskthemepack`、`.theme`、`.msstyles`；
- 光标：`.cur`、`.ani`、`.inf`、`.curxptheme`；
- 图标包：`.7tsp`。

Rexon 会把它们转换为 `.rxn` 软件包并安装：软件包会出现在“我的扩展”中，主题本身则出现在
[外观](appearance.md) 中对应类型的版块里，并在那里应用。

### 查找扩展

在搜索栏中输入名称、作者名或标签。要只保留某一类软件包，请点击搜索栏下方相应类型的按钮；
“全部”会取消筛选。

### 启用或禁用

点击磁贴上的 **▶️ 启用**，底部会出现“▶️ 已启用：…”。要禁用，点击 **⏸️ 禁用**。
主题和字体没有这个按钮：它们只是处于已安装状态，在 [外观](appearance.md) 中应用。

### 移除

1. 在磁贴上或“扩展”窗口中点击 **🗑️ 移除**。
2. 在“移除扩展？”窗口中确认。扩展的文件会被永久删除。

### 制作自己的 `.rxn` 扩展

点击 **自己制作**。Rexon 会显示一份说明：`.rxn` 就是一个普通的 ZIP 压缩包，里面有
`manifest.json` 文件（名称、版本、作者、类型）、用于目录的图片以及扩展本身的文件。
说明中有 `manifest.json` 的示例和类型列表。

![“制作自己的 .rxn 扩展”说明](../images/extensions-create.png)

## 出了问题怎么办

- **“⚠️ 已有安装正在进行”。** 等上一次安装或移除完成后再试一次。
- **“⚠️ 错误：…”。** 文件已损坏，或者它不是 Rexon 扩展。冒号后面的文字会说明原因。
  如果“已安装”一行带有附注（例如找不到转换 Windows 主题所需的程序），说明扩展已安装，
  但并不完整。
- **“⚠️ 无法启用或禁用：…”。** 扩展未能启用或禁用。注销后重新登录通常能解决，
  尤其是 GNOME 和 Cinnamon 扩展。
- **启用扩展后桌面表现异常。** 用 **⏸️ 禁用** 按钮禁用它，或者把它移除。
  如果桌面彻底坏了，请登录到另一个桌面，然后在 [桌面环境](desktops.md) 标签页中
  出问题的桌面卡片上点击 **🔧 检查 / 修复**。
- **小心工具和插件。** 这两类软件包会运行自己的安装和卸载脚本（以你的用户身份运行，
  没有管理员权限）。只安装你信任的人提供的软件包。
